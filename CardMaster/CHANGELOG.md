# 更新记录

## 1.1.169 — 2026/10/17

- 卡牌总览中，未收藏卡牌在悬浮时临时显示正常彩色缩略图，并允许右侧完整卡牌及扫光预览；移开或卡牌隐藏后恢复未收藏的褪色、遮罩及占位样式。
- 已收藏卡牌移开后保持正常显示；缺贴图时保留安全占位和提示，不尝试加载已知缺失贴图。检查贴图完成后，仍悬浮的卡牌可直接预览。
- 预览只改变临时界面状态，不写入收藏记录，不改变抽卡池或收藏进度。
- 收藏提示在 Logo 后恢复黄色“卡牌大师”（其他客户端语言为 `CardMaster`），移除末尾“通告”入口，改为可点击／悬浮预览的“点击文字可预览卡牌”。不恢复受保护的自动表情发送，兼容旧聊天记录中已失效的通告链接。
- 分类勾选框保持默认黄色，并按截图从上一版位置向左上各移动 8 个 UI 单位。
- 四个模块的 TOC、运行时及窗口版本统一为 `1.1.169`。

## 1.1.168 — 2026/10/17

- 修复收藏奖励回调自动发送表情通告导致的 `ADDON_ACTION_BLOCKED`。本地提示与音效照常；开启对外播报时提供“通告”链接，点击填入原生聊天框，按回车发送，不再自动调用受保护聊天函数。
- 收藏提示改为 Logo +“获得第 N 套卡牌新收藏”，不再显示套牌名称；职业名按客户端职业色，首领／史诗／种族技能和御龙术按史诗紫色显示。
- 分类和总体进度分别着色：不足 50% 为红色，50% 至未满为黄色，全部完成为绿色。
- 兼容 Glass 自定义及复用消息行、延迟创建的聊天窗口与原生聊天事件，保留卡名悬浮扫光预览及点击固定预览。
- 分类收藏勾选恢复客户端默认黄色，向图标右下方外移，减少与图标点击区域的重叠。
- 四个模块的 TOC、运行时及窗口版本统一为 `1.1.168`。离线回归不替代六客户端实际游戏验收。

## 1.1.167 — 2026/10/17

- 四个模块版本由 `1.0.167` 统一调整为 `1.1.167`。
- 补充原生聊天链接悬浮启用与无参数移开处理；Glass 使用独立消息行的兼容问题在 `1.1.168` 继续修复。
